PipBeats - APK banane ka tareeqa (PC ki zaroorat nahi)
1) github.com pe free account banao > New repository (naam: pipbeats, Public)
2) "uploading an existing file" pe click karo, is folder ki SAARI files/folders upload karo
   (www, .github, package.json, capacitor.config.json) > Commit
   Note: .github folder upload hona zaroori hai (hidden folder hai, drag-drop se jata hai)
3) Repo mein Actions tab > "Build APK" chalne do (5-8 min)
4) Green hone par us run mein neeche Artifacts > PipBeats-APK download karo
5) Zip extract karo, app-debug.apk phone mein install karo (Unknown sources allow karna paray ga)
Criteria tune karne ke liye www/engine.js ke upar CFG badlo.
